# Spendry – Personal Finance & Expense Splitter

A smart and lightweight web application for **personal budgeting, expense tracking, and group bill splitting**, built using **HTML, CSS, JavaScript, and Firebase**.  
Spendry helps users understand where their money goes, split costs in groups, settle balances, and sync data online via Firebase.

## 🚀 Project Overview (From SRS)

### Functional Requirements
- User Authentication, Profile Management
- Expense Tracking (Personal & Group)
- Bill Splitting (Equal)
- Group Settlements 
- Spending Insights & Category Reports
- PDF/CSV Export
- Firebase Sync & Data Handling
- Notifications & Budget Alerts

### Non-Functional Requirements
- Load time < 6 seconds
- 1,000+ users supported
- Responsive UI/UX
- Modular code structure
- Secure group access
- Scalable to 10,000+ users

### Future Enhancements
- AI-based budget suggestions
- UPI & Banking integration
- Multi-currency support
- Gamification features
